# Eshra Campus Circle

Create a beautiful, modern, mobile-first web app called BDE ESHRA for students at ESHRA in Algeria. Use dark navy, white, and elegant gold accents. Include a home dashboard, announcements, events, student clubs, polls, suggestions, profiles, and a messaging section. Add responsive navigation and an admin dashboard. Use realistic sample data. Make it look like a polished university community app. Do not connect any database yet.
